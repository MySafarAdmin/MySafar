# Security

The dashboard holds children's personal data. If you think you've found a
security problem (for example, someone seeing classrooms they shouldn't, or
signing in without a password), don't post it publicly. Email
mysafaradmin@gmail.com with what you saw and how to repeat it.

To stop someone's access straight away, an admin can turn off their account on
**Manage users**; that also signs them out everywhere.
